## Status buttons (on assigned call)

When your unit is on the call:

| Button | Meaning |
|--------|---------|
| **DISPATCHED** | Acknowledge assignment |
| **EN ROUTE** | En route to scene |
| **ON SCENE** | Arrived on scene |
| **CLEAR CALL** | Clear your unit from call |

Requires network — offline shows **No network connection. Try again when online.**

<Note>Screenshot placeholder: DISPATCHED / EN ROUTE / ON SCENE button row</Note>

## Assign yourself

If you are not yet assigned to this call, tap **ASSIGN MY UNIT**.

Units can be on more than one open call. That is the default.

If an agency turns **off** **Allow a field unit on multiple open calls** in Web Admin:

1. If you are already on another open call, Cadmus asks you to **clear or close that call first**.
2. Cancel leaves you on the first call and does not assign this one.
3. **Clear / close that call** uses the same Clear myself vs close flow as **CLEAR CALL**. If you are the only unit left on the first call, you close it — you cannot leave it with no unit.
4. After that call is cleared or closed, Cadmus assigns you to this call.

## Call sections

| Section | Content |
|---------|---------|
| **CALL TYPE** | Incident type and priority |
| **PRIMARY UNIT** | Primary assigned unit |
| **REPORTING PARTY** | Caller info |
| **PERSONS INVOLVED** | Suspects, victims, witnesses |
| **VEHICLES INVOLVED** | Vehicle records |
| **History & Logs** | Notes and audit trail |
