MDT settings beyond voice alerts and training mode.

## Voice and assignment alerts

**Voice Alerts** (Settings):

| Control | Effect |
|---------|--------|
| **Incoming call alerts** toggle | Speaks your custom phrase when a **new** call is assigned |
| **Custom phrase** | Text spoken for new assignments (e.g. “You have a call.”) |

When speech is off or the app is backgrounded, Android may show a **Call Assignments** notification instead. See [Voice alerts](/mobile/voice-alerts).

## Hardware and peripherals

**HARDWARE & PERIPHERALS** lists printers available to the device (including Bluetooth printers already paired with the OS).

| Control | Purpose |
|---------|---------|
| **Refresh** | Reload the system printer list |
| **TEST 4″** | Send a 4″ × 8″ thermal test page |
| **TEST LETTER** | Send an 8.5″ × 11″ letter test page |

Select a printer in the list, then run a test. If no printers appear, pair the printer in Android Bluetooth / print settings and refresh — or use a test button to open the system print dialog.

App version is shown at the bottom of this section.

## Location services

**LOCATION SERVICES** controls GPS permissions and manual start/stop for **handheld** officer tracking.

| Control | Purpose |
|---------|---------|
| Permission status | Shows whether the app can read GPS |
| **Start** / **Stop** | Begin or end person location updates (handheld) |
| Accuracy readout | Current fix quality when tracking is active |

<Note>
On **desktop MDT** and **activated apparatus tablets**, location tracking for the unit starts automatically when you are signed in (or the device session is active). The Settings start/stop buttons apply to handheld person tracking; apparatus tablets fall back to the enrolled **unit id** when no officer profile is present.
</Note>

See [Map and navigation](/mobile/map-and-navigation) for how MDT vs phone tracking appears on the map.

## Application updates (Windows MDT)

On Windows production builds, MDT checks for signed updates when you start the app and about every four hours while it stays open and online.

- Open **Updates** from the sidebar to read release notes and see download progress.
- When the chip shows **Update ready — restart to install**, choose **Restart to update** or close and reopen the app.
- The installer runs on restart and relaunches MDT with the new version.

Updates are verified before installation. Offline or slow networks may delay download; the previous version remains usable until a verified update is staged.

## Application updates (Windows MDT)

On **Windows** MDT builds with auto-update enabled:

| Control | Effect |
|---------|--------|
| **Automatically download updates** | Off by default. When off, Cadmus checks for updates in the background and asks before downloading. When on, updates download quietly, then Cadmus still asks before installing. |
| **Check for updates** / **Download & install** / **Restart to update** | Manual control from Settings |
| **Later** | Postpone the prompt for 24 hours and keep using the current version |

Install always requires confirmation. If Windows asks for administrator approval and you cancel, you can keep working on the current version and retry later.

## Tips

- Set display mode once per shift type (day vs night).
- Pair the thermal printer in system settings, then run **TEST 4″** before the first citation stop.
- Run **CHECK UPDATES** after admin pushes new violation codes.
