## Sandbox and Live

If your login includes paired **Sandbox** and **Live** organizations, the top bar shows **SANDBOX** or **LIVE**.

1. Tap the badge to switch to the opposite space (Sandbox → Live, or Live → Sandbox).
2. You must already have membership in both organizations. Production MDT only offers Sandbox and Live — not an arbitrary organization list.
3. After a successful switch, Calls, Units, Map, and E-Citations reload for the new organization. A short reconnect is expected.
4. If the switch fails, the message tells you whether the organization change failed or live data did not reconnect. Retry from **Settings** if lists look stale.

The same switch is available in Settings when a pair exists.

## Display mode

**SYSTEM CONFIGURATION** → **DISPLAY MODE**

| Mode | Use |
|------|-----|
| **Normal** | Standard colors |
| **Night Vision** | Reduced glare for night patrol |
| **Monitor Blackout** | Minimal screen output when required |
