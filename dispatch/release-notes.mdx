## Unit View filters and live partner calls

Dispatch CAD now keeps your call-board and **Active Units** agency selections across ordinary **Reload Data**, and authorized organization-wide boards receive partner-agency call creates live.

### What changed

- **Retained agency filters** — Call-board and Active Units (Unit View) agency picks are saved per signed-in dispatcher and organization. Choosing **All**, clearing to none, or selecting a subset round-trips after restart and after you sign back in on a shared workstation.
- **Reload Data preserves selections** — Header and recovery-banner **Reload Data** refresh the board and live connection without resetting agency filters to everyone.
- **Live partner-agency calls** — Dispatchers, Org Admins, Agency Admins, and Cadmus Admins on an organization-wide board see another agency’s new calls appear within seconds over the live connection—no manual refresh required. Agency-only roles stay limited to their own agency.

### What to expect

- Shared workstations keep each dispatcher’s own saved filters; signing out clears the on-screen selection for the next person but does not erase that dispatcher’s saved preference.
- Switching organizations restores only that organization’s saved filters for the current user.
- If a partner call still fails to appear while the live connection looks healthy, treat that as unexpected and escalate—do not rely on repeated manual reloads as normal workflow.

## Quick-call assignment SMS (Traffic Stop hotfix)

Officer-initiated **Traffic Stop** quick calls now text opted-in personnel as soon as a unit is selected. Closing the call is not required.

- Assignment SMS uses the same eligibility rules as board assign (phone on file, SMS on assign enabled, not in Do Not Disturb).
- Traffic stops still do **not** send an Active911 page.
- Other quick calls that assign a unit at create time (for example **Paper Service**) already sent assignment SMS immediately, including when the unit starts **On Scene**.

See [Quick Calls & F-Keys](/dispatch/quick-calls-fkeys).

## Query person fields match MULES

Name / DOR and related person queries now use the same values dispatchers type in MULES:

- Full name is `LAST,FIRST` or `LAST, FIRST` (comma, with or without a space; not underscore)
- Birth date is `YYYYMMDD`
- Sex is `M`, `F`, or `U`

See [Queries & NCIC](/dispatch/queries-ncic) and [Query commands](/dispatch/query-commands).

## Fuel logs — pump readings and dispatcher DSN

Dispatchers can record optional **beginning** and **ending pump** readings when logging fuel. Cadmus can prefill beginning pump from the agency’s last ending reading, shows a gallons-vs-pump-difference hint without blocking save, and snapshots the signed-in dispatcher’s **DSN** with the entry. See [Fuel Logs](/dispatch/fuel-logs).

## Windows startup recovery

- Cadmus now recovers damaged local workstation settings that previously left the app opening minimized or frozen.
- Invalid saved window positions are reset to a visible display instead of requiring a full AppData reset.
- Launching Cadmus again while it is already running restores the existing window instead of stacking frozen processes.
- Cadmus sends a privacy-safe recovery diagnostic automatically; preference file contents are never uploaded.

## Client v1.0.60 — Active Units agency grouping

- **Group by Agency** — the Active Units sidebar can show agency section headers with unit counts so mixed-agency consoles can locate units faster during call assignment.
- **Flat list preserved** — switch back to **Flat** anytime to keep the existing single-list view and API order.
- **Local preference** — organization mode is saved on this workstation and does not change how other dispatchers see Active Units.
- **Agency filters remembered** — **Select Agencies** on the call-list side rail and the Active Units agency filter are saved per dispatcher and organization on this workstation. Another dispatcher on the same PC gets their own saved filter after they sign in.

## Client v1.0.54 — St. Clair dispatch UX

- **Font size** — Settings & tools → Display → Font size (100%, 110%, 125%, or 150%) enlarges text on this workstation.
- **Edit Crew** — right-click an on-duty unit to add crew without a full logout. Needs a matching Cadmus server update.
- **Close as Desk Call** — close a CFS with no primary-agency field units; Cadmus records a Dispatch Desk unit. Needs a matching server update.
- **Close Panel** — quick action (formerly **Clear**) closes the call detail window only; it does not close the CFS. Use **Close Call** in the app bar to finalize.
- **Edit call notes** — correct a posted note; Cadmus shows **Edited** and **View original**. Needs a matching server update.
- **Report a Bug** — no longer opens automatically on every error; send feedback from Settings when you need it.

## Shared workstations, board recovery, and unit vehicles

- **Shared-workstation session isolation** — use **Sign Out** from the user menu between dispatchers on the same Windows login so the prior session and agency filters do not carry forward.
- **Live-board recovery guidance** — dashboard banners identify when the call board cannot load, the live connection is lost, a prior refresh is being shown, or agencies are unavailable. Use **Reload Data** or **Retry now** as prompted.
- **Vehicle display for units** — vehicle names appear beneath a unit's callsign in **Login User** (F2) and the **Active Units** sidebar. Search by a vehicle identifier, such as **24-01**, to find its unit.

## CJIS response feedback and result review

Cadmus now provides consistent status feedback and result viewing for authorized CJIS queries in the Query Workspace and call detail.

- Query entries distinguish sent or pending, completed hit, completed no-hit, timeout, and error states.
- You can reopen completed entries from **Recent Queries** and a call's **CJIS Query History**.
- Results provide a parsed view and the authoritative raw response. An authorized DOR photo view appears when an image is available.
- DOR license statuses distinguish suspended, revoked, no operators, valid, and unknown results.
- Returned warrant and protection-order indicators appear independently from the overall hit/no-hit status.
- Mobile officers receive the same response feedback and can review parsed, raw, and available photo results from **NCIC Search → RESPONSES**.
- Mobile spoken summaries use approved high-level statuses and do not read raw CJIS content aloud.

<Note>
  These improvements do not add a separate Ex Parte or Order of Protection query type. Existing State/NCIC permissions and Law Enforcement restrictions continue to apply.
</Note>
