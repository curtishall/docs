## St. Clair Go-Live Recovery Updates

- **Shared-workstation session isolation** — dispatchers are reminded to use **Sign Out** from the user menu between users on the same Windows login, helping prevent a prior dispatcher's session and agency filters from carrying forward.
- **Live-board recovery guidance** — dashboard banners now identify when call-board data cannot load, the live connection is lost, a prior refresh is being shown, or agencies are unavailable. Use **Reload Data** or **Retry now** as prompted.
- **Vehicle display for units** — vehicle names now appear beneath a unit's callsign in **Login User** (F2) and the **Active Units** sidebar. Search by a vehicle identifier, such as **24-01**, to find its unit.
