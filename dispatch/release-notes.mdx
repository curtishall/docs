## CJIS response feedback and result review

Cadmus now provides consistent status feedback and result viewing for authorized CJIS queries in the Query Workspace and call detail.

- Query entries distinguish sent or pending, completed hit, completed no-hit, timeout, and error states.
- You can reopen completed entries from **Recent Queries** and a call's **CJIS Query History**.
- Results provide a parsed view and the authoritative raw response. An authorized DOR photo view appears when an image is available.
- DOR license statuses distinguish suspended, revoked, no operators, valid, and unknown results.
- Returned warrant and protection-order indicators appear independently from the overall hit/no-hit status.
- Mobile officers receive the same response feedback and can review parsed, raw, and available photo results from **NCIC Search → RESPONSES**.
- Mobile spoken summaries use approved high-level statuses and do not read raw CJIS content aloud.

<Note>
  These improvements do not add a separate Ex Parte or Order of Protection query type. Existing State/NCIC permissions and Law Enforcement restrictions continue to apply.
</Note>
