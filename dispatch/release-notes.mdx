## Web Admin: load GIS data into a dataset

Organization administrators can upload a GIS **zip** archive in **GIS Management**, load it into the organization’s dataset for the chosen type, validate the candidate, and **Publish** when ready. Dispatch CAD does not show the layer until publish.

See [GIS Data Management](/admin/gis-data-management).
