## Incoming 911 ANI/ALI events

Cadmus Dispatch can receive traditional PSAP ANI/ALI spills through an onsite 911 gateway:

- Non-blocking **Incoming 911** popup with callback, location, wireless class, and accuracy
- Persistent **911** tray and claim collaboration so only one dispatcher creates the CFS
- Prefill into **New CFS**
- Local delivery continues when Cadmus Cloud is offline (CFS create waits for cloud)

See [Incoming 911 events](/dispatch/incoming-911-events).
