## Incoming 911 ANI/ALI events

Cadmus Dispatch can receive traditional PSAP ANI/ALI spills through an onsite 911 gateway:

- Non-blocking **Incoming 911** popup with callback, location, wireless class, and accuracy
- Persistent **911** tray and claim collaboration so only one dispatcher creates the CFS
- Prefill into **New CFS**
- Local delivery continues when Cadmus Cloud is offline (CFS create waits for cloud)

### Location timeline and confirmed CFS updates

- **Location updated** badge when ALI rebids arrive (Initial → Updated / Last known)
- **Show on map** focuses one event’s numbered trail, uncertainty circles, and fit-to-view
- Agency-wide **911 Calls** map layer defaults **off** to avoid clutter
- Attached rebids append a CFS note automatically; address/coordinates change only after **Apply latest location to CFS** confirmation

See [Incoming 911 events](/dispatch/incoming-911-events) and [Map and location](/dispatch/map-and-location).
