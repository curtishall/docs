<Tip>
Your **aliases** may differ from the defaults below. In **Dispatch CAD**, press **F1** or type **`HELP`** for the live list. Type **`HELP <command>`** (for example **`HELP VIEW`**) to open detailed usage and examples for one command. Tap any row in the help dialog to expand it.
</Tip>

## Getting help in the app

| What you type | What happens |
|---|---|
| `HELP` or `?` or **F1** | Opens the full command reference dialog |
| `HELP VIEW` | Opens the same dialog focused on **VIEW** with usage and examples |
| Tap a command row | Expands usage, examples, arguments, and related commands |

CJIS query commands (**DL**, **LP**, **NAME**, **CQ**, **AH**, **UH**, **S**) appear in help marked as **CJIS relay — use CJIS panel**.

## Call management

| Default | Action | Dashboard | In-call |
|--------|--------|-----------|---------|
| NC | New call | `NC <TYPE> <ADDRESS> [@UNIT] [!STATUS] [RP=] [PH=] ["narrative"]` | — |
| CLOSE | Close call | `CLOSE <CFS#>` | `CLOSE` |
| REOPEN | Reopen | `REOPEN <CFS#>` | `REOPEN` |
| VIEW | Open call detail | `VIEW <CFS#>` or `VIEW #<CFS#>` | — |
| SEND | Promote active | `SEND <CFS#>` | `SEND` |
| PENDING | Set pending | `PENDING <CFS#>` | `PENDING` |

### VIEW

Opens the call in Call Detail when the CFS exists.

- `VIEW #2026000014`
- `VIEW 2026000014`

## Call properties (in-call)

| Form | Example | Notes |
|------|---------|-------|
| PRI= | `PRI=2` | Autocomplete after `PRI=` (1–4) |
| TYPE= | `TYPE=ASS` | Autocomplete types/shortcodes that **start with** what you type |
| LOC= | `LOC=456 ELM ST` | Multi-word address |
| NARR= | `NARR=Caller reports…` | Adds a note on the call |
| N | `N Caller advises disregard` or `N "test 123"` | Note appears immediately on the call |
| RP= / PH= | Reporting party | |
| NS | `NS` | No-status-check flag (audit today) |

## Status timers (open call required)

| Command | Behavior |
|---------|----------|
| `STATUS ON` | **One agency** on the call → starts that agency’s status timer. **Multiple agencies** → error listing agencies; use `STATUS ON @AgencyName`. **No agency rows** → call-level enable. |
| `STATUS OFF` | Same single / multi / call-level rules to stop timers |
| `STATUS ON @Agency` | Start (or create) that agency’s timer |
| `STATUS OFF @Agency` | Disable that agency’s timer |
| `STATUS 10` | Set call-level timer to 10 minutes |
| `STATUS 0` | Stop call-level timer |

## Queries (CJIS)

Use the **CJIS panel** for full query workflows. Command-line **DL** / **LP** / **NAME** / **CQ** may relay supported types; **AH** / **UH** / **S** are listed in help as CJIS relay stubs.
